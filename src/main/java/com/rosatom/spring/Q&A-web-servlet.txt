Вопросы для подготовки Web:
- Что такое www?
World Wide Web. система гипертекстовых документов и ресурсов,
связанных между собой ссылками и URL, доступных через интернет.



- Что такое w3c?
World Wide Web Consortium
международная организация, которая разрабатывает
 стандарты и рекомендации для развития Всемирной паутины.


- Что такое TCP/IP?
Transmission Control Protocol/Internet Protocol):
Это набор протоколов, используемых для связи в сети интернет.


- Что такое ftp?
Протокол передачи файлов,
который используется для копирования файлов между компьютерами в сети.


- Чем отличаются http и https?
Hypertext Transfer Protocol
стандартный протокол передачи данных, а HTTPS (HTTP Secure)
 - это защищенная версия HTTP, которая использует шифрование



- Что такое протокол передачи данных, какие вы знаете?
набор правил и структур, используемых для передачи данных между компьютерами.
HTTP, FTP, SMTP


- Что такое web server?
программное обеспечение, которое хранит, обрабатывает и
предоставляет веб-содержимое браузерам клиентов. Он обслуживает
HTTP-запросы и предоставляет веб-страницы.


- Что такое web приложение?
программное обеспечение, которое работает на веб-сервере
и предоставляет взаимодействие с пользователями через веб-браузеры.
Примеры включают веб-почту, социальные сети,



- Что такое application server?
программное обеспечение, которое обеспечивает
выполнение бизнес-логики веб-приложения.
Оно может управлять сеансами, безопасностью, базами данных



- Чем отличаются web server и application server?
Веб-сервер обслуживает HTTP-запросы и предоставляет
статические веб-страницы, в то время как сервер приложений
выполняет более сложную бизнес-логику веб-приложения.



- Какие методы передачи данных вы знаете?
GET, POST



- Чем отличаются методы get и post?
GET используется для запросов на получение данных,
POST - для отправки данных на сервер.
GET данные передаются через URL, POST - в теле запроса.


- Что такое html?
Hypertext Markup Language
Язык разметки, используемый для создания веб-страниц


- Что такое xml?
eXtensible Markup Language
Язык разметки для хранения и передачи данных в структурированном форматe


- Что такое css?
Cascading Style Sheets
Язык таблиц стилей, используемый для оформления и стилизации веб-страниц.


- Что такое MIME type?
Multipurpose Internet Mail Extensions
метка, используемая для указания типа данных,
передаваемых в сети. MIME-типы используются для правильной
интерпретации контента, например, текстовых файлов, изображений


- Что такое cookies?
небольшие текстовые файлы, которые веб-сервер отправляет на компьютер
пользователя и которые браузер сохраняет. Они используются для хранения
информации о состоянии сеанса и для отслеживания пользователей


- Что такое сессия?
способ отслеживать состояние пользователя на веб-сайте.
Она обычно устанавливается после аутентификации и позволяет
хранить информацию о пользователе между запросами.



- Дайте определение понятиям “авторизация” и “аутентификация”, в чем их различия?
Authentication - процесс проверки личности пользователя.
Пользователь предоставляет учетные данные, и система проверяет их,
чтобы удостовериться, что он - это тот, за кого себя выдаёт.

Авторизация: Это процесс управления доступом пользователя к определенным
ресурсам или функциям на основе его аутентификации.



- Что такое Ajax? Как принципиально устроена эта технология?
Asynchronous JavaScript and XML
технология, которая позволяет веб-страницам взаимодействовать с
сервером без необходимости перезагрузки всей страницы. Это достигается
с использованием асинхронных запросов к серверу, обработки данных и
обновления только необходимых частей страницы.






Вопросы для подготовки Servlets:
- Что такое сервлет?
Java-класс, предназначенный для обработки HTTP-запросов и генерации HTTP-ответов.
Сервлеты выполняются на сервере приложений и используются для создания
динамических веб-приложений.



- Что такое контейнер сервлетов?
часть сервера приложений, которая управляет жизненным циклом сервлетов,



- Каковы задачи, функциональность контейнера сервлетов?
загрузку и инициализацию сервлетов, управление потоками выполнения,
обработку HTTP-запросов и маршрутизацию к соответствующим сервлетам



- Что вы знаете о сервлет фильтрах?
предоставляют механизм для выполнения фильтрации запросов и ответов,
проходящих через сервлет. Они могут использоваться для изменения
запросов или ответов, а также для применения различных манипуляций перед
или после обработки сервлета.



- Зачем нужны слушатели в сервлетах?
позволяют реагировать на события, связанные с жизненным циклом
сервлетов, контекстом приложения и сессиями.



- Когда вы будете использовать фильтры, а когда слушатели?
Фильтры используются для манипуляций с запросами и ответами перед и
после их обработки сервлетом, в то время как слушатели используются для
обработки событий, связанных с сервлетами, контекстом приложения и сессиями.



- Что такое дескриптор развертывания?
Дескриптор развертывания (web.xml) - это конфигурационный файл веб-приложения,
который описывает, как сервлеты и другие ресурсы должны быть развернуты и
настроены в приложении.



- Что представляет собой объект ServletConfig?
ServletConfig представляет конфигурацию сервлета и позволяет
ему получать параметры и настройки из дескриптора развертывания



- Что представляет собой объект ServletContext?
представляет контекст сервлета, обеспечивая доступ к
общим ресурсам и настройкам приложения.



- В чем отличия ServletContext и ServletConfig?
ServletConfig - это конфигурация конкретного сервлета,
в то время как ServletContext - это контекст приложения,
общий для всех сервлетов в приложении.



- Что такое Request Dispatcher?
механизм перенаправления запросов с одного сервлета
на другой в пределах одного веб-приложения.



- Как можно создать блокировку (deadlock) в сервлете?
сли два или более сервлета блокируют ресурсы, необходимые друг другу,
и не могут разблокировать их из-за взаимной блокировки.



- Как получить адрес сервлета на сервере?
getServletPath() на объекте HttpServletRequest.



- Как получить информацию о сервере из сервлета?
ServletContext#getServerInfo



- Как получить ip адрес клиента на сервере?
getRemoteAddr() на объекте HttpServletRequest.



- Каков жизненный цикл сервлета и когда какие методы вызываются?
Жизненный цикл сервлета включает методы init(), service(), doGet(), doPost(), destroy(),
и они вызываются в следующем порядке: init(), service(),
doGet() или doPost() (в зависимости от типа запроса), destroy()`.



- Какие методы необходимо определить при создании сервлетов?
вы должны переопределить методы doGet() или doPost(),
а также, возможно, метод init() и destroy().



- В каком случае вы будете переопределять метод service()?
Обычно не рекомендуется переопределять метод service(),
так как это делается для обработки разных типов HTTP-запросов,



- В чем отличия GenericServlet и HttpServlet?
GenericServlet - это абстрактный класс, предоставляющий базовую реализацию
интерфейса Servlet. HttpServlet - это подкласс GenericServlet, предназначенный
для обработки HTTP-запросов



- Как вызвать из сервлета другой сервлет этого же и другого приложения?
выполняется с использованием URL, содержащего контекст приложения и путь к сервлету.



- Что вы знаете и в чем отличия методов forward() и sendRedirect()?
forward() используется для внутреннего перенаправления запроса на другой ресурс
в рамках одного запроса, в то время как sendRedirect() используется для отправки
клиента на другой ресурс, возможно в другом приложении.



- Стоит ли волноваться о “многопоточной безопасности” работая с сервлетами?
стоит заботиться о многопоточной безопасности, так как сервлеты могут быть
одновременно вызваны несколькими потоками. Важно грамотно синхронизировать
доступ к ресурсам и переменным



- В чем отличие между веб сервером и сервером приложений?
Веб-сервер обычно обрабатывает HTTP-запросы и возвращает статические ресурсы,
в то время как сервер приложений предоставляет среду выполнения для веб-приложений,
включая сервлеты и JSP.



- Какой метод HTTP не является неизменяемым?
POST является изменяемым, так как он может изменять состояние сервера
или выполнять действия, несмотря на одинаковые запросы.




- В чем разница между методами GET и POST?
GET используется для запроса данных, POST - для отправки данных на сервер.
GET данные передаются в URL, POST передает данные в теле запроса.
GET запросы могут быть кэшированы, в то время как POST нет.

- В чем разница между PrintWriter и ServletOutputStream?
PrintWriter используется для записи текстовых данных, таких как HTML-код,
XML-документы и т.д. ServletOutputStream используется для записи бинарных
данных, таких как изображения, аудио- и видеофайлы и т.д.



- Что означает URL encoding? Зачем нужны методы java.net.URLEncoder.encode() и decode()?
 процесс преобразования символов в URL-адресе в безопасный формат,
 который может быть передан по сети. Некоторые символы, такие как пробелы и
 знаки пунктуации, не могут быть переданы в URL-адресе напрямую и должны быть
 закодированы.
 java.net.URLEncoder.encode() и decode() используются для кодирования
 и декодирования URL-адресов соответственно.



- Какие различные методы управления сессией в сервлетах вы знаете?
request.getSession() - создает новую сессию или возвращает существующую.
session.setAttribute(String name, Object value) - устанавливает атрибут сессии с указанным именем и значением.
session.getAttribute(String name) - возвращает значение атрибута сессии с указанным именем.
session.invalidate() - удаляет сессию и все ее атрибуты.



- Что означает URL Rewriting?
процесс изменения URL-адреса в HTTP-ответе, чтобы добавить дополнительную
информацию, такую как идентификатор сессии или параметры запроса. Это может быть
полезно, когда требуется передать информацию между страницами или сохранить
состояние между запросами. URL Rewriting может быть выполнен с помощью методов
HttpServletResponse.encodeURL() и HttpServletResponse.encodeRedirectURL().



- Как применяются Cookies в сервлетах?
механизм хранения данных на стороне клиента в виде пар "имя-значение".
В сервлетах, Cookies могут быть использованы для хранения информации о
пользователе, такой как идентификатор сессии, предпочтения пользователя и т.д.
Cookies могут быть установлены с помощью метода HttpServletResponse.addCookie()
и получены с помощью метода HttpServletRequest.getCookies().



- Как уведомить объект в сессии, что сессия недействительна или закончилась?
 путем реализации интерфейса HttpSessionListener и переопределения методов
 sessionCreated() и sessionDestroyed(). Метод sessionCreated() вызывается при
 создании новой сессии, а метод sessionDestroyed() - при уничтожении сессии.



- Как мы можем обеспечить transport layer security для нашего веб приложения?
transport layer security (TLS) для веб-приложения, можно использовать протокол
HTTPS вместо HTTP. HTTPS - это HTTP, работающий поверх протокола SSL/TLS, который
обеспечивает шифрование данных и аутентификацию сервера. Для использования HTTPS,
необходимо получить сертификат SSL/TLS от доверенного центра сертификации и
настроить веб-сервер для работы с HTTPS.



- Какие важные особенности существуют в Servlet 3?
Асинхронная поддержка - позволяет сервлетам выполняться асинхронно,
Аннотации - позволяют использовать аннотации для настройки сервлетов, вместо XML-конфигурации.
Фрагменты web.xml - позволяют разбить файл web.xml на несколько файлов для упрощения конфигурации.
Поддержка WebSocket - позволяет создавать веб-приложения, которые могут использовать протокол
    WebSocket для обмена данными в режиме реального времени.



- Каковы различные способы аутентификации сервлета?
HTTP Basic Authentication - это метод аутентификации, который использует
    базовую аутентификацию HTTP. При использовании этого метода, клиент отправляет
    запрос на сервер, содержащий заголовок Authorization, который содержит имя
    пользователя и пароль в закодированном виде.
HTTP Digest Authentication - это метод аутентификации, который использует
    дайджест-аутентификацию HTTP. При использовании этого метода, клиент отправляет
    запрос на сервер, содержащий заголовок Authorization, который содержит
    хэш-значение пароля вместо самого пароля.
Форма аутентификации - это метод аутентификации, который использует форму
    для ввода имени пользователя и пароля. При использовании этого метода,
    клиент отправляет запрос на сервер, содержащий данные формы, которые затем
    проверяются на сервере.
Кастомная аутентификация - это метод аутентификации, который позволяет
    разработчикам реализовать свой собственный механизм аутентификации,
    который может быть интегрирован с существующей системой аутентификации.



- Что такое Java Server Pages (JSP)?
технология программирования на стороне сервера, которая позволяет создавать
динамические веб-страницы. JSP использует язык разметки HTML и язык
программирования Java для создания страниц, которые могут быть динамически
изменены в зависимости от данных,



- Зачем нужен JSP?
 создания динамических веб-страниц, которые могут быть изменены в
 зависимости от данных, полученных от пользователя или из базы данных.
 Он позволяет разработчикам создавать веб-страницы, которые могут быть
 адаптированы к различным устройствам и разрешениям экрана,



- Опишите, как обрабатываются JSP страницы, начиная от запроса к серверу, заканчивая ответом пользователю.
Когда пользователь отправляет запрос на сервер, контейнер сервлетов обрабатывает
запрос и передает его на обработку JSP-странице. Сначала JSP-страница
компилируется в сервлет, который затем выполняется на сервере. В процессе
выполнения сервлет получает данные из базы данных или от пользователя,
обрабатывает их и генерирует HTML-код, который затем отправляется обратно
на клиентскую сторону в виде ответа на запрос. Клиентский браузер затем
отображает HTML-код на экране пользователя.



- Расскажите об этапах (фазах) жизненного цикла JSP.
Translation - в этой фазе JSP-страница переводится в сервлет.
Compilation - в этой фазе сервлет компилируется в байт-код.
Classloading - в этой фазе байт-код загружается в память.
Instantiation - в этой фазе создается экземпляр сервлета.
Initialization - в этой фазе сервлет инициализируется.
Request processing - в этой фазе сервлет обрабатывает запросы.
Destroy - в этой фазе сервлет уничтожается.



- Расскажите о методах жизненного цикла JSP.
jspInit() - этот метод вызывается при инициализации сервлета и
    используется для инициализации ресурсов, таких как базы данных
    или файловые системы.
jspService() - этот метод вызывается для обработки каждого
    запроса и используется для генерации HTML-кода, который будет отправлен
    обратно на клиентскую сторону.
jspDestroy() - этот метод вызывается при уничтожении сервлета и используется
    для освобождения ресурсов, таких как базы данных или файловые системы.



- Как закомментировать код в JSP?
<%-- --%>


- Какие существуют основные типы тегов JSP?
Директивы - используются для указания настроек страницы, таких как импорты, переменные и т.д. Пример: <%@ page import="java.util.*" %>
Скрипты - используются для вставки кода Java в страницу. Пример: <% int x = 5; %>
Выражения - используются для вставки значения переменной или выражения в страницу. Пример: <%= x %>
Объявления - используются для объявления переменных и методов, которые могут быть использованы в других частях страницы. Пример: <%! int y = 10; %>



- Что такое JSTL (JSP Standard tag library)?
предоставляет набор стандартных тегов для использования в JSP-страницах.
Она позволяет упростить написание кода и уменьшить количество повторяющегося кода.
JSTL включает теги для работы с условными операторами, циклами, форматированием
дат и чисел, работой с коллекциями



- Из каких групп тегов состоит библиотека JSTL?
Core - содержит основные теги для работы с условными операторами, циклами и т.д.
Formatting - содержит теги для форматирования дат и чисел.
SQL - содержит теги для работы с базами данных.
XML - содержит теги для работы с XML-документами.
