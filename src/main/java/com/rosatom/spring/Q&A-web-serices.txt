Вопросы:
- Что такое веб сервисы?
Веб-сервисы представляют собой программные приложения или сервисы,
которые предоставляют функциональность через сеть, обычно по протоколу HTTP.
Они позволяют взаимодействовать с другими программами или приложениями через сеть
Интернет. Веб-сервисы широко используются для обмена данными между различными
системами и интеграции различных приложений.


- Какие виды веб-сервисов вы знаете?
SOAP (Simple Object Access Protocol): Это протокол обмена структурированными
    информационными сообщениями в формате XML. SOAP включает в себя определение
    структуры сообщения и правил взаимодействия.
REST (Representational State Transfer): REST является архитектурным стилем для
    построения веб-сервисов. Он основан на принципах, таких как использование
    HTTP методов (GET, POST, PUT, DELETE) и представление ресурсов в виде уникальных URI.
JSON-RPC и XML-RPC: Это протоколы удалённого вызова процедур, позволяющие вызывать
    функции и передавать данные в формате JSON или XML по сети.
GraphQL: Это язык запросов для API, который позволяет клиентам запрашивать
    только те данные, которые им необходимы. Он предоставляет более гибкий способ
    взаимодействия с сервером по сравнению с традиционными REST API.
Microservices (Микросервисы): Это архитектурный подход, при котором приложение
    разбивается на небольшие, автономные службы, каждая из которых выполняет конкретную
    функцию. Каждый микросервис может предоставлять свой собственный веб-сервис.
WebSocket: Это протокол связи поверх TCP, который обеспечивает полнодуплексное
    взаимодействие между клиентом и сервером. WebSocket подходит для сценариев,
    где необходимо активное взаимодействие между клиентом и сервером.

- Что такое SOAP?
SOAP (Simple Object Access Protocol) - это протокол обмена структурированными
сообщениями в распределенных вычислительных средах, таких как веб-сервисы.
Он использует XML для форматирования сообщений и обычно передается через протокол HTTP.


- Объясните понятие WSDL.
WSDL (Web Services Description Language) - это язык описания веб-сервисов,
который предоставляет информацию о том, как взаимодействовать с веб-службой.
WSDL определяет операции, входные и выходные сообщения, протоколы и форматы сообщений.


- Что такое JAX-WS?
JAX-WS (Java API for XML Web Services) - это набор API для создания веб-сервисов
с использованием Java. Он предоставляет инструменты для разработки веб-сервисов
в соответствии с стандартами SOAP.


- Расскажите о JAXB.
JAXB (Java Architecture for XML Binding) - это технология в Java для преобразования
объектов Java в XML и обратно. Она используется, например, для маппинга
Java-объектов на структуры XML, которые могут быть переданы через SOAP.


- Можем ли мы посылать soap сообщения с вложением?
Да, SOAP позволяет включать вложения (attachments) в сообщения.
Это может быть полезно, например, для передачи файлов или изображений.


- Что такое MTOM в SOAP?
MTOM (Message Transmission Optimization Mechanism) - это стандарт веб-сервисов,
который оптимизирует передачу бинарных данных, таких как изображения или документы,
через SOAP. Он позволяет вложениям быть отправленными в отдельном потоке данных,
уменьшая таким образом накладные расходы на кодирование.


- Что такое XOP в SOAP?
XOP (XML-binary Optimized Packaging) - это стандарт, который определяет,
как вложения могут быть представлены в XML-документе для более эффективной
передачи бинарных данных в SOAP-сообщениях.


- Что такое SOAP envelope.
SOAP Envelope - это обертка вокруг сообщения в протоколе SOAP.
Она содержит заголовки (headers) и тело (body) сообщения.


- Как определяется пространство имен SOAP?
Пространство имен SOAP определяется URI-адресом, который указывается в атрибуте
xmlns:soap в элементе Envelope. Например,
xmlns:soap="http://www.w3.org/2003/05/soap-envelope".


- Что вы знаете о кодировании в SOAP (encoding)?
SOAP может использовать различные методы кодирования данных, такие как XML,
DIME (Direct Internet Message Encapsulation) или MTOM/XOP для бинарных данных.
XML является стандартным методом кодирования для текстовых данных.


- Что определяет атрибут encodingStyle в SOAP?
Атрибут encodingStyle в SOAP указывает на метод кодирования данных в сообщении.
Он определяет, какие правила должны использоваться для преобразования данных в
формат XML.


- Какие два конечных типа веб сервисов используют JAX-WS?
JAX-WS поддерживает два типа веб-сервисов: Document-style и RPC-style.
В Document-style каждая операция веб-сервиса представлена как элемент в
XML-документе, в то время как в RPC-style операции представлены как вызовы
удаленных процедур.


- Расскажи о wsimport, зачем он нужен?
wsimport - это утилита, предоставляемая JAX-WS, которая генерирует Java-код (стабы)
из WSDL-описания веб-сервиса. Этот сгенерированный код можно затем использовать
для создания клиента веб-сервиса на стороне клиента.


- Расскажи о wsgen, зачем он нужен?
wsgen - это утилита, предоставляемая JAX-WS, которая генерирует WSDL-описание
веб-сервиса и код (скелеты) для его реализации на стороне сервера на Java-кодe.


- Какие вы можете выделить различия между SOAP и другими техниками удаленного доступа?
SOAP основан на XML и может использоваться через различные протоколы (обычно HTTP),
    в то время как другие техники удаленного доступа могут использовать разные
    форматы данных и протоколы (например, JSON-RPC, REST).
SOAP предоставляет строгую структуру для описания веб-сервисов с использованием WSDL,
    в то время как другие методы могут быть менее формализованными.
SOAP обеспечивает стандартные механизмы обработки ошибок и безопасности,
    что может быть важно в некоторых приложениях.


- Что такое Apache CXF?
Apache CXF - это открытый исходный код фреймворк для разработки веб-сервисов
с использованием различных протоколов, включая SOAP. Он предоставляет инструменты
для создания клиентов и серверов веб-сервисов на платформе Java.


- Что такое Metro?
Metro - это проект с открытым исходным кодом, предоставляющий реализацию технологий
для веб-сервисов на платформе Java, включая JAX-WS. Metro является стандартной
реализацией JAX-WS для платформы Java.


- Как можно использовать инструмент SOAP UI?
SOAP UI - это инструмент для тестирования веб-сервисов. С его помощью можно создавать,
отправлять и получать SOAP-запросы, а также проводить тестирование и отладку
веб-сервисов. Он поддерживает различные протоколы, включая SOAP, REST, HTTP и другие.

REST:
- Что такое REST?
REST (Representational State Transfer) - это архитектурный стиль для построения
распределенных приложений, основанный на принципах, определенных Роем Филдингом.
REST использует стандартные протоколы, такие как HTTP, для передачи и обмена данными
между клиентом и сервером.


- Что такое resource в REST?
Ресурс в REST - это любая информация или служба, представленная в вебе и
идентифицируемая уникальным URI (Uniform Resource Identifier). Ресурсы могут
быть как конкретными объектами (например, запись в базе данных), так и более
абстрактными службами.


- Какие HTTP методы поддерживаются в REST?
GET: Получение данных с сервера.
POST: Создание нового ресурса.
PUT: Обновление существующего ресурса или создание нового, если ресурс не существует.
DELETE: Удаление ресурса.


- Каково соответствие CRUD-операций в REST-сервисах и HTTP-методов?
CREATE: POST
READ: GET
UPDATE: PUT
DELETE: DELETE


- Когда можно использовать GET запрос вместо POST для создания ресурса?
Согласно принципам REST, следует использовать POST для создания ресурса, а не GET.
GET используется для запроса данных, и использование его для создания ресурса не
соответствует семантике HTTP методов.


- Какая разница между GET и POST запросами?
GET: Используется для запроса данных от сервера. Данные передаются в URL, ограничены
    по размеру, и могут быть закэшированы. Не должен использоваться для отправки
    конфиденциальной информации.
POST: Используется для отправки данных на сервер. Данные передаются в теле запроса,
    не ограничены по размеру, и не кэшируются. Часто используется для создания ресурсов.


- Что означает WADL?
WADL (Web Application Description Language) - это язык описания веб-сервисов,
предназначенный для описания RESTful веб-сервисов. Он аналогичен WSDL, но применяется
для описания REST-сервисов.


- Какие вы знаете фреймворки, которые реализуют REST веб сервисы?
Spring Boot: Предоставляет поддержку для создания RESTful веб-сервисов.
Express (Node.js): Фреймворк для Node.js, который обеспечивает поддержку RESTful веб-сервисов.
Django REST framework: Расширение фреймворка Django для создания RESTful веб-сервисов.
Flask (Python): Легкий фреймворк для Python, который позволяет создавать RESTful веб-сервисы.


- Какая разница между AJAX и REST?
AJAX (Asynchronous JavaScript and XML): Это технология для обновления части
    веб-страницы без перезагрузки всей страницы. Он использует асинхронные запросы
    к серверу для получения данных.
REST: Это архитектурный стиль для построения распределенных приложений,
    ориентированный на ресурсы и основанный на принципах HTTP. RESTful веб-сервисы
    обеспечивают доступ к данным через стандартные HTTP-методы.


- Что делает аннотация @Path?
@Path - это аннотация, используемая в JAX-RS (Java API for RESTful Web Services),
чтобы указать путь URI для ресурса или метода ресурса.


- Что делает аннотация @PathParam?
@PathParam - это аннотация, используемая в JAX-RS для извлечения значения
переменной из URI-шаблона и передачи ее в метод ресурса.


- Что делает аннотация @QueryParam?
@QueryParam - это аннотация в JAX-RS, используемая для извлечения значения
параметра запроса из URL и передачи его в метод ресурса.


- Что делает аннотация @MatrixParam?
@MatrixParam - это аннотация в JAX-RS, используемая для извлечения значения
параметра матрицы из URI и передачи его в метод ресурса.


- Что делает аннотация @FormParam?
@FormParam - это аннотация в JAX-RS, используемая для извлечения значения параметра
из тела формы и передачи его в метод ресурса.


- Какие два способа получения заголовка HTTP запроса в JAX-RS вы знаете?
Использование аннотации @HeaderParam для извлечения значения конкретного заголовка.
Использование объекта @Context HttpHeaders для извлечения всех заголовков.


- Как скачать файл с помощью JAX-RS?
Для скачивания файла с помощью JAX-RS можно использовать StreamingOutput
или Response с указанием заголовка "Content-Disposition".


- Что такое HATEOAS?
HATEOAS (Hypermedia as the Engine of Application State) - это принцип архитектуры REST,
который предполагает, что клиент может взаимодействовать с веб-службой, используя только
гипермедийные ссылки, предоставленные динамически в ответе сервера.

- Что такое curl?
curl - это утилита командной строки для отправки HTTP-запросов и получения ответов.
Она поддерживает множество протоколов, включая HTTP, HTTPS, FTP и другие.


- Для чего нужен инструмент Postman?
Postman - это инструмент для разработки и тестирования API. Он предоставляет
графический интерфейс для отправки HTTP-запросов, проверки ответов и автоматизации
тестирования API.


- В чем разница между REST и SOAP веб сервисами? Когда какой лучше использовать?
REST: Основан на принципах архитектуры, таких как использование уникальных
    URI и HTTP методов. Обычно использует форматы данных как JSON или XML.
    Легковесен и прост в использовании.
SOAP: Использует XML для форматирования данных и имеет строгий стандарт для
    описания веб-сервисов (WSDL). Чаще всего использует HTTP, но не ограничен
    этим протоколом. Более тяжеловесен и может быть сложным в реализации.
Выбор между REST и SOAP зависит от конкретных требований проекта. REST часто
предпочтителен для простых и легковесных систем, в то время как SOAP может быть
более подходящим для сложных систем, где важна структурированность и надежность.

- Что такое GraphQL?
GraphQL - это язык запросов и среда выполнения для API, разработанный Facebook.
Он позволяет клиентам запрашивать только те данные, которые им необходимы, и
предоставляет единый интерфейс для множества источников данных.


- Что такое query в GraphQL?
Запрос (query) в GraphQL - это структурированный запрос клиента к серверу,
в котором указываются данные, необходимые клиенту. Запросы GraphQL написаны
в специальном синтаксисе, который описывает не только структуру данных, но и
форму предоставления этих данных.


- Что такое resolvers в GraphQL?
Resolver - это функция, которая определяет, каким образом выполнить запрос
GraphQL для определенного типа или поля. Она указывает, откуда получить данные
для запрошенных полей.


- Что такое schema в GraphQL?
Схема (schema) в GraphQL определяет типы данных, которые могут быть запрошены,
и их отношения. Она предоставляет клиентам информацию о том, какие запросы они
могут делать и какие данные они могут получить в ответ.


- Подход GraphQL отличается от REST?
Гранулярность запросов: В GraphQL клиент может запросить только те данные,
    которые ему нужны, в отличие от REST, где ответ сервера заранее определен.
Единый конечный пункт: В GraphQL обычно используется единый конечный пункт (endpoint),
    в то время как в REST каждый ресурс имеет свой уникальный URL.
Схема данных: GraphQL использует явно определенную схему данных, что облегчает
    клиентам понимание и использование API.

- Что такое GRPC?
gRPC - это фреймворк для разработки эффективных и расширяемых распределенных систем,
основанный на протоколе Protocol Buffers.


- Что такое Proto формат? Как он устроен?
Proto (Protocol Buffers) - это формат сериализации данных, а также язык описания
интерфейса для описания структуры данных и сервисов. Он бинарный формат, компактный
и быстрый, а также является читаемым и понятным для человека.


- Что такое unary call в grpc?
Unary call в gRPC - это простой вызов, где клиент отправляет один запрос
и получает один ответ от сервера.


- Что такое streaming в grpc?
Streaming в gRPC подразделяется на два вида:
Server streaming: Клиент отправляет запрос,
    а сервер отвечает потоком сообщений.
Client streaming: Клиент отправляет поток сообщений,
    а сервер отвечает одним сообщением.
В обоих случаях, как только сообщение отправлено, его можно получить
сразу после отправки. Это позволяет создавать более эффективные и
гибкие распределенные системы.
