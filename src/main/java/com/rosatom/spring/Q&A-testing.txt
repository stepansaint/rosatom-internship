Что такое юнит-тестирование?
Вид тестирования, при котором отдельные компоненты программы: методы или классы,
тестируются изолированно от остальной системы.
Цель - проверить, что каждый компонент работает корректно.


Что такое интеграционное тестирование?
Это тестирование, при котором различные компоненты программы объединяются
и тестируются вместе для проверки их взаимодействия.
Цель - обнаружить ошибки в интеграции компонентов.


В чем отличия между ними?
Юнит-тестирование фокусируется на тестировании отдельных компонентов,
тогда как интеграционное тестирование проверяет взаимодействие между компонентами.


Что такое e2e-тестирование?
End-to-End тестирование, при котором тестируется вся система с точки зрения
пользователя, от начала до конца.
Цель - проверка работы системы в условиях, максимально приближенных к реальным.


Что такое UI-тестирование?
Тестирование пользовательского интерфейса для проверки его корректной работы
и соответствия требованиям.


Что такое mock?
Объект, имитирующий поведение реального объекта в контролируемой среде.
Используется для тестирования компонентов, которые зависят от других компонентов.

Что такое stub?
Это объект, заменяющий реальный компонент программы и предоставляющий
фиксированные данные или ответы.
Используется для управления возвращаемыми значениями в тестах.


Что такое «фикстуры»?
Это предварительно настроенные данные или условия,
используемые при выполнении тестов.
Гарантируют, что тесты выполняются в одинаковых условиях.


Какие аннотации существуют в JUnit? Что они делают?
@Test: метод является тестовым.
@Before: метод, который выполняется перед каждым тестом.
@BeforeClass: метод, который выполняется один раз перед всеми тестами в классе.
@After: метод, который выполняется после каждого теста.
@AfterClass: метод, который выполняется один раз после всех тестов в классе.
@Ignore: помечает тестовый метод для временного/постоянного исключения из выполнения.

Что вы знаете о Spring Test?
Spring Test - часть фреймворка Spring, предоставляющая поддержку
для тестирования приложений, основанных на Spring.
Он включает в себя различные аннотации (например, @RunWith(SpringRunner.class)),
которые облегчают интеграцию тестов с контекстом Spring,
а также предоставляет классы, такие как MockMvc для тестирования контроллеров.


Что такое TestContainers и в чем его удобство?
TestContainers - это библиотека для создания и управления временными контейнерами
(например, Docker) во время выполнения тестов.
Удобство заключается в том, что она позволяет запускать тесты
в изолированных средах, что особенно полезно для интеграционного тестирования,
например, с базами данных.

и проверка содержимого страницы.
Selenium поддерживает различные языки программирования,
такие как Java, Python, C#, и другие.

Что такое Page Object?
Page Object - это шаблон проектирования, используемый в тестировании
веб-приложений с помощью Selenium. Каждая страница в приложении представляется
отдельным классом, который содержит локаторы элементов и методы для
взаимодействия с этими элементами.
Это облегчает обслуживание тестов при изменениях в веб-приложении.



Расскажите о селекторах в Selenium.

Селекторы используются для нахождения элементов на веб-странице
и взаимодействия с ними в тестах. Некоторые типы селекторов включают в себя:
ID: driver.findElement(By.id("elementId"))
Name: driver.findElement(By.name("elementName"))
Class Name: driver.findElement(By.className("elementClass"))
Tag Name: driver.findElement(By.tagName("tagName"))
Link Text: driver.findElement(By.linkText("linkText"))
Partial Link Text: driver.findElement(By.partialLinkText("partialLinkText"))
CSS Selector: driver.findElement(By.cssSelector("cssSelector"))
XPath: driver.findElement(By.xpath("xpathExpression"))

XPath (XML Path Language): Это язык для навигации по XML-документам,
который также может быть использован для нахождения элементов на веб-страницах.
В Selenium, выражения XPath часто используются для создания сложных
запросов к элементам. Примеры:
//input[@id='username']: Найти элемент <input> с атрибутом id равным 'username'.
//div[@class='content']//a: Найти все элементы <a> внутри элемента с классом 'content'.
Selenium WebDriver в сочетании с Page Object позволяет эффективно
автоматизировать веб-приложения, обеспечивая удобство сопровождения
и повторное использование кода.
