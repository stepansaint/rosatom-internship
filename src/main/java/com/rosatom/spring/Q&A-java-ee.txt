- Что такое Java EE / Jakarta EE?
Java EE (Java Platform, Enterprise Edition) - это набор спецификаций
и API для разработки и выполнения распределенных серверных приложений в языке программирования
Java. Jakarta EE - это продолжение Java EE после переноса технологии в фонд Eclipse.



- Какие модули входят в Java EE?
CDI
Enterprise JavaBeans (EJB):
    Компоненты для разработки бизнес-логики.
Java Servlets и JavaServer Pages (JSP):
    Для создания веб-приложений.
Java Persistence API (JPA):
    Для взаимодействия с базами данных.
Java Transaction API (JTA):
    Для управления транзакциями.
Java Message Service (JMS):
    Для обмена сообщениями между компонентами приложения.
Java Naming and Directory Interface (JNDI):
    Для доступа к каталогам и сервисам.
JavaMail:
    Для работы с электронной почтой.
Java API for XML Web Services (JAX-WS):
    Для создания веб-сервисов.
Java API for RESTful Web Services (JAX-RS):
    Для создания RESTful веб-сервисов.
JavaServer Faces (JSF):
    Для создания веб-интерфейсов.
Java Connector Architecture (JCA):
    Для взаимодействия с корпоративными информационными системами.
Batch Processing API:
    Для обработки данных в пакетном режиме.



- Что такое Application Server?
Все спецификации Jakarta EE реализованы (Tomcat например только Servlets and JSP спецификацию - он называет себя Servlet Container)
Application Server - это программное обеспечение, предоставляющее среду выполнения
для развертывания, управления и выполнения приложений, созданных с
использованием технологий Java EE или Jakarta EE.



- Расскажите о Glassfish.
GlassFish - это открытый исходный код сервер приложений.
Он предоставляет реализацию технологий
Jakarta EE, таких как EJB, JPA, JAX-RS, и других.
от Eclipse.



- Расскажите о JBoss.
JBoss (теперь WildFly) - это сервер приложений с открытым исходным кодом,
предоставляющий реализацию технологий Java EE и Jakarta EE.
Он поддерживает множество расширений и интегрируется с другими технологиями
от Red Hat.



- Расскажите о WebLogic.
WebLogic Server - это коммерческий сервер приложений.
Он предоставляет полноценную реализацию Java EE и Jakarta EE,
поддерживает масштабирование и высокую доступность.

IBM WebSphere Application Server - это коммерческий сервер приложений,

от IBM



- Какая разница между .jar, .war и .ear файлами?
.jar (Java Archive): Используется для упаковки библиотек Java,
    приложений и ресурсов в один архив.  - может быть запущен на VM
.war (Web Archive): Используется для упаковки веб-приложений,
    включая сервлеты, JSP, HTML-страницы, и другие веб-ресурсы. - требуется сервер для запуска
.ear (Enterprise Archive): Используется для упаковки корпоративных приложений, -- могут содержать ejb компоненты, jar, war
    включая EJB, веб-приложения, и другие компоненты.

- Расскажите о Bean Validation.
Bean Validation - это спецификация в Java EE для валидации данных
в объектах Java. Она предоставляет аннотации для определения правил валидации.





- Расскажите о JAX-RS.
JAX-RS (Java API for RESTful Web Services) - это спецификация в Java EE
для создания RESTful веб-сервисов. Она предоставляет аннотации для
определения ресурсов, методов и формата данных.




- Расскажите о JAX-WS.
JAX-WS (Java API for XML Web Services) - это спецификация в Java EE
для создания веб-сервисов, основанных на XML. Она предоставляет
аннотации для определения служб веб-сервисов.




- Расскажите о JSON-B.
JSON-B - это спецификация в Java EE для преобразования
объектов Java в формат JSON и обратно.




- Расскажите о JSON-P.
JSON-P (Java API for JSON Processing) - это спецификация в Java EE
для работы с данными в формате JSON. Она предоставляет API для чтения,
записи и манипулирования данными JSON.




- Расскажите о JSF.
JSF (JavaServer Faces) - это фреймворк в Java EE для создания пользовательских
интерфейсов в веб-приложениях. Он предоставляет компоненты и управление
состоянием для разработки веб-интерфейсов.



- Расскажите о Java EE Security.
Java EE Security - это спецификация в Java EE, предоставляющая средства
для обеспечения безопасности в приложениях, включая аутентификацию,
авторизацию и управление ролями.



- Расскажите о Java EE Messaging / JMS.
JMS (Java Message Service) - это спецификация в Java EE для работы
с асинхронным обменом сообщениями между компонентами приложения.



- Расскажите о JavaMail.
JavaMail - это API в Java EE для отправки и получения
электронной почты из приложений Java.



- Расскажите о Java Transaction API (JTA).
JTA (Java Transaction API) - это спецификация в Java EE для управления
транзакциями в распределенных приложениях. Она предоставляет средства для
обеспечения атомарности и целостности транзакций.
