- Расскажите о принципах обобщенного программирования (generic programming)
парадигма программирования, которая заключается в таком описании данных
и алгоритмов, которое можно применять к различным типам данных,
не меняя само это описание
Основные принципы:
Абстрагирование: выделение общих понятий и создание абстрактных типов данных,
    которые могут быть использованы для описания различных конкретных типов данных.
Иерархия: создание иерархии типов данных, которые наследуют свойства и методы
    от более общих типов.
Типизация: использование параметризованных типов данных, которые могут быть
    применены к различным типам данных.
Основными достоинствами обобщенного программирования являются
    повышение универсальности и переносимости программного кода,
    а также уменьшение количества дублирующегося кода.
    Однако, недостатками являются сложность в понимании и использовании,
    а также возможность ухудшения производительности из-за необходимости
    дополнительных проверок типов данных.


- Расскажите о принципах аспектно-ориентированного программирования (AOP)
парадигма, которая позволяет разделять функциональность программы на отдельные модули,
    называемые аспектами. Аспекты могут быть использованы для реализации
    функциональности, которая не относится к основной логике программы,
    такой как логирование, проверка безопасности и т.д.
Основные принципы AOP включают в себя:
Разделение функциональности: разделение функциональности программы на
    отдельные модули, которые могут быть использованы повторно.
Аспекты: создание аспектов, которые могут быть использованы для реализации
    функциональности, которая не относится к основной логике программы.
Советы: определение советов, которые определяют, когда и как аспекты
    должны быть применены.
Срезы: определение срезов, которые определяют, когда и на какие части
    программы должны быть применены аспекты.
Основными достоинствами AOP являются повышение модульности
    и переносимости программного кода, а также уменьшение количества
    дублирующегося кода.
Однако, недостатками являются сложность в понимании и использовании,
а также возможность ухудшения производительности из-за необходимости дополнительных проверок


- Расскажите о принципах функционального программирования (functional programming)
парадигма, которая основана на использовании функций в качестве основных
    элементов программы. Основные принципы функционального программирования
    включают в себя:
Чистота функций: функции должны быть чистыми, то есть не иметь побочных эффектов
    и всегда возвращать одинаковый результат для одинаковых входных данных.
Неизменяемость данных: данные должны быть неизменяемыми, то есть после создания
    не могут быть изменены.
Рекурсия: использование рекурсии для описания алгоритмов.
Высшие порядки функций: использование функций в качестве аргументов
    и возвращаемых значений других функций.
Основными достоинствами функционального программирования являются
    упрощение понимания и тестирования программного кода,
    а также возможность параллельного выполнения кода.
Однако, недостатками являются сложность в понимании и использовании,
а также возможность ухудшения производительности из-за необходимости создания
большого количества объектов



- Что вы знаете о рефакторинге? Принципы рефакторинга кода
Рефакторинг - процесс изменения программного кода с целью улучшения его качества,
    без изменения его функциональности.
Основные принципы рефакторинга включают в себя:
Упрощение кода: для читаемости и понимания.
Удаление дублирующегося кода: для уменьшения объема.
Улучшение архитектуры: для уменьшения связности и повышения ее модульности.
Улучшение производительности: оптимизация алгоритмов и структур данных.


- Какие вы знаете принципы оптимизации производительности кода?
Принципы оптимизации производительности кода включают в себя использование
    эффективных алгоритмов и структур данных,
    минимизацию операций ввода-вывода,
    оптимизацию запросов к базе данных,
    параллельное выполнение задач и кэширование результатов.


- Что вы знаете о асинхронном выполнении задач?
Асинхронное выполнение задач - это подход, при котором задачи выполняются
независимо друг от друга, что позволяет улучшить отзывчивость программы.
В языках программирования, таких как JavaScript, асинхронное выполнение задач
обычно реализуется с помощью колбэков, промисов или асинхронных функций


- Расскажите про работу с транзакциями
Работа с транзакциями включает в себя выполнение нескольких
операций как единое целое, так чтобы либо все операции были выполнены успешно,
либо ни одна из них не была выполнена.
Транзакции обеспечивают целостность данных в базе данных


- Какие существуют проблемы при работе с транзакциями
Проблемы при работе с транзакциями включают в себя блокировки,
дедлоки, уровни изоляции транзакций и вытекающие феномены


- Какие существуют уровни изоляции транзакций?
Уровни изоляции транзакций определяют уровень доступа к данным для
одной транзакции и влияют на параллельное выполнение транзакций.
READ_UNCOMMITED, READ_COMMITED, REPEATABLE_READ, READ_SERIALIZABLE


- Что такое файловая система?
Файловая система - это метод организации и хранения данных
на носителях информации, таких как жесткие диски, флеш-накопители и т.д.
Файловая система определяет структуру файлов, их именование, доступ и хранение


- Какие виды файловых систем вы знаете?
FAT, NTFS, exFAT, HFS+, ext4, APFS.
Каждая файловая система имеет свои особенности
и предназначена для определенных операционных систем и устройств


- Что вы знаете о логировании в Java?
Логирование в Java - это процесс записи информации о работе программы
в специальные файлы, называемые логами.
Есть JUL - Java's.


- Расскажите о log4j
Log4j - это популярная библиотека для логирования в Java.
Она предоставляет гибкие настройки для записи логов различного уровня,
их фильтрацию и хранение в различных местах, таких как файлы, базы данных и т.д.



- Расскажите о slf4j
SLF4J (Simple Logging Facade for Java) - это простая библиотека для логирования в Java,
который позволяет использовать различные библиотеки логирования,
такие как logback, log4j и java.util.logging,
без необходимости изменения кода приложения



- Расскажите о logback
Logback - это библиотека логирования для Java,
которая представляет собой улучшенную версию библиотеки log4j.
Она обладает высокой производительностью, гибкой настройкой и
поддержкой различных уровней логирования



- Какие уровни логирования вы знаете?
Уровни логирования включают в себя TRACE, DEBUG, INFO, WARN, ERROR и FATAL.
Уровень TRACE используется для наименьшей важности сообщений,
а уровень FATAL - для наибольшей важности


- Что такое APPENDER?
APPENDER в логировании - это компонент, который определяет,
куда и каким образом будут выводиться логи.
Например, файловый аппендер может выводить логи в файл,
а консольный аппендер - на консоль



- Что такое json?
JSON (JavaScript Object Notation) - это формат обмена данными,
основанный на синтаксисе JavaScript. Он широко используется для передачи
структурированных данных между клиентом и сервером



- Какие вы знаете java-библиотеки дл работы с json?
Jackson, Gson



- Расскажите о Jackson
Jackson - это мощная библиотека для работы с JSON в Java.
Она позволяет преобразовывать Java-объекты в JSON и обратно,
а также выполнять другие операции с JSON


- Расскажите о Gson
Gson - это библиотека для работы с JSON в Java,
разработанная компанией Google.
Она предоставляет простые методы для преобразования Java-объектов в JSON и обратно


- Что такое CSV?
CSV (Comma-Separated Values) - это формат хранения табличных данных,
в котором значения разделены запятыми.


- Какие вы знаете java-библиотеки дл работы с CSV?
Некоторые из популярных Java-библиотек для работы с CSV включают
OpenCSV, Apache Commons CSV и uniVocity-parsers


- Что такое YAML?
YAML (YAML Ain't Markup Language) - это удобочитаемый формат сериализации данных,
который широко используется для конфигурационных файлов и обмена данными между
приложениями



- Что такое XML?
XML (Extensible Markup Language) - это язык разметки,
который используется для хранения и передачи структурированных данных.
Он широко применяется в веб-разработке и обмене данными между приложениями


- Что такое XSD?
XSD (XML Schema Definition) - это язык описания структуры XML-документов.
XSD-схемы используются для определения допустимой структуры и
содержимого XML-документов



- Что такое XSLT?
XSLT (Extensible Stylesheet Language Transformations) - это язык преобразования
XML-документов. Он позволяет преобразовывать XML-документы в различные форматы,
такие как HTML, текст и другие XML-документы


- Что такое xPath?
XPath - это язык запросов для выбора узлов в XML-документах.
Он позволяет осуществлять навигацию и поиск данных в XML-структурах


- Расскажите о SAX API в java
SAX (Simple API for XML) - это API для обработки XML-документов в Java.
Он позволяет осуществлять последовательное чтение и обработку XML-данных
без необходимости загрузки всего документа в память


- Расскажите о DOM API в java
DOM (Document Object Model) - это API для представления и манипулирования
XML-документов в виде дерева объектов.
DOM API позволяет загружать весь XML-документ в память и работать с ним
как с деревом объектов


- Чем отличают DOM и SAX?
Основное отличие между DOM и SAX заключается в подходе к обработке XML-документов.
DOM загружает весь документ в память и представляет его в виде дерева объектов,
в то время как SAX осуществляет последовательное чтение документа без его полной
загрузки в память


- Какие http-клиенты для java вы знаете?
HttpClient - стандартный клиент HTTP в Java,
    который позволяет выполнять асинхронные и блокирующие запросы к серверам.
OkHttpClient - современный и высокопроизводительный клиент HTTP,
    который поддерживает асинхронное выполнение запросов, кэширование и сертификацию.
Apache HttpComponents Client - мощный и гибкий клиент HTTP,
    который предоставляет настройку поддержки для множества протоколов и схем.


- Расскажите о шаблонизаторах Mustache, Freemarker, Velocity
Mustache - шаблонизатор который позволяет вставлять данные в шаблон строки.
Freemarker - мощный шаблонизатор с поддержкой динамических шаблонов,
    встроенных функций и фильтров.
Velocity - шаблонизатор с поддержкой встраиваемых шаблонов,
    макросов и директив.


- Что такое Swagger? Какие у него есть возможности?
Swagger - это спецификация API, которая позволяет описывать,
настраивать и генерировать документацию для API.
Она предоставляет возможности для автоматического сгенерации кода клиентов,
серверных частей и интерфейсов.


- Что такое Postman? Какие у него есть возможности?
Postman - это инструмент для разработки API, который позволяет тестировать
и разрабатывать API-интерфейсы. Он предоставляет возможности для отправки
запросов, анализа ответов и тестирования кода.


- Что такое SOAP UI? Какие у него есть возможности?
SOAP UI - это инструмент для тестирования и разработки веб-сервисов и API.
Он предоставляет возможности для отправки запросов, анализа ответов
и генерации кода клиентов.


- Что такое миграция схемы бд и данных?
Миграция схемы БД и данных - это процесс перехода с одной версии схемы базы данных
на другую. Это может включать в себя автоматическое обновление схемы,
копирование данных и тестирование приложений на новой схеме.


- Расскажите о Liquibase? Какие у него есть возможности?
Liquibase - это инструмент для управления версиями схем баз данных.
Он позволяет автоматически управлять изменениями в схеме базы данных,
отслеживать изменения и тестировать приложения на новой схеме.


- Расскажите о Flyway? Какие у него есть возможности?
Flyway - это инструмент для управления версиями схем и данных.
Он предоставляет возможности для миграции схемы, обновления данных
и тестирования приложений на новой схеме.


- Что такое Lombok? Какие у него есть возможности?
Lombok - это библиотека для Java, которая предоставляет возможности
для автоматического создания классов с бизнес-логикой, такой как сериализация,
десериализация, валидация и т.д.
