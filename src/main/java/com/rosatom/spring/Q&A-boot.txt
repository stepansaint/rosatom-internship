- Что такое Spring Boot?
предоставляет множество функций, таких как управление зависимостями,
автоматическая конфигурация и встроенные контейнеры сервлетов.



- Какие преимущества у Spring Boot?
Легкость в конфигурации, что убирает множество кода
Интеграция с другими Spring frameworks



- Как он работает? Как он понимает что и как нужно сконфигурировать?
использует конфигурацию по умолчанию, которая позволяет ему автоматически
 сконфигурировать приложение на основе классов и аннотаций,
 которые находятся в classpath.



- Что влияет на настройку Spring Boot?
Используемые зависимости, аннотации



- Как определяются property? Где находится дефолтный PropertySource в Spring Boot?
Property в Spring Boot определяются с помощью файлов свойств,
которые могут быть размещены в разных местах, таких как classpath,
файловая система или переменные среды.
Дефолтный PropertySource в
Spring Boot - это application.properties / application.yaml в classpath



- Опишите основные аннотации и конфиги для Spring Boot?
@SpringBootApplication (@Configuration, @EnableAutoConfiguration, @ComponentScan)
, @RestController, @RequestMapping, @Autowired, @Value



- В чем различия между встроенным контейнером и WAR?
Встроенный контейнер в Spring Boot позволяет запускать приложение без
установки отдельного контейнера сервлетов. WAR-файлы, напротив, требуют наличия контейнера
сервлетов для запуска приложения (Tomcat).



- Какие встроенные контейнеры поддерживает Spring?
По умолчанию Tomcat (контейнер сервлетов)
Spring поддерживает встроенные контейнеры Tomcat, Jetty и Undertow.



- Что делает @EnableAutoConfiguration?
@EnableAutoConfiguration - для Spring Boot
автоматически настраивать бины основываясь на зависимостях.



- Делает ли Spring Boot сканирование компонентов? Где он их ищет по умолчанию?
сканирование @Component (это и @Service, @Repository, @Controller)
 в пакете, где находится класс @SpringBootApplication.



- Что такое Spring Boot Starter POM? Чем он может быть полезен?
Spring Boot Starter POM - это набор зависимостей,
которые могут быть использованы для быстрого создания приложений в Spring Boot
(веб-приложение, приложение с доступом к бд)



- Какие Spring Boot startes вы знаете?
 spring-boot-starter-web,
 spring-boot-starter-data-jpa,
 spring-boot-starter-security



- Как подключить Spring Boot starter?
с помощью Maven или Gradle.

Делаем класс с аннотацией @AutoConfigureAfter который ссылается на первый
