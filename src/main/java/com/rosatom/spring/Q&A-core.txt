Core:
- Что такое Spring Framework.
платформа для разработки приложений на языке Java


- Каковы некоторые из важных особенностей и преимуществ Spring Framework?
Инверсия управления (IoC) и внедрение зависимостей (DI),
Аспектно-ориентированное программирование (AOP)


- Что вы понимаете под Dependency Injection (DI)?
Dependency Injection (DI) - это процесс внедрения зависимостей
в объекты, которые они используют


- Как реализуется DI в Spring Framework?
с помощью контейнера Spring IoC


- Что такое IoC контейнер Spring?
IoC контейнер Spring - компонент Spring Framework,
который управляет созданием объектов и их зависимостей.


- Что такое Spring бин?
это объект, управляемый контейнером Spring IoC


- Каковы различные способы настроить класс как Spring Bean?
xml,
java-code,
@Component, @Service, @Repository


- Какие вы знаете различные scope у Spring Bean?
https://www.baeldung.com/spring-bean-scopes#2-session-scope
singleton - 1 экземляр для всего контейнера (по-умолчанию)
prototype - каждый раз при запросе у контейнора
request - для каждого http-запроса
session - для каждой сессии http
application - для ServletContext



- Как работает scope Prototype?
новый экземпляр бина каждый раз, когда он запрашивается из контейнера


- Каков bean scope по умолчанию в Spring Framework?
bean scope - singleton


- Что такое жизненный цикл Spring Bean?
можем управлять благодяра init и destroy методам
инициализация бина и его уничтожение


- Что такое связывание в Spring и расскажите об аннотации @Autowired?
DI позволяет связывать объект в другие объекты, которые его используют
@Autowired используется для автоматической инъекции зависимостей



- Каковы различные типы автоматического связывания в Spring?
https://dzone.com/articles/autowiring-in-spring
связывание по типу (by type) - Spring ищет бин, который соответствует типу поля
связывание по имени (by name) - Spring ищет бин, который соответствует имени поля,
связывание по квалификатору (by qualifier) - Spring ищет бин, который соответствует квалификатору поля



- Как вы решаете какой бин инжектировать, если у вас несколько подходящих бинов.
    Расскажите о @Primary и @Qualifier?
@Primary для указания первичного бина
@Qualifier для указания конкретного бина, который должен быть использован для инъекции



- Как мы можем проводить инъекцию бинов в Spring?
с помощью аннотации @Autowired
с помощью конструктора
с помощью сеттера
xml
java-code



- Какой способ инъекции бинов является лучшим и почему?
через конструктор (например, сразу видно циклические зависимости; также лучше в плане ооп: делаем поля final и объект полностью готов к полноценному функционированию)



- Что такое ApplicationContext?
 расширяет BeanFactory и предоставляет дополнительные функции,
 такие как интернациализация (из нее вытекает возможность локализации).
Управляет жизненным циклом бинов и их зависимостей, загрузка ресурсов


https://www.baeldung.com/spring-beanfactory-vs-applicationcontext
- В чем разница между BeanFactory и ApplicationContext?
ApplicationContext загружает все бины при запуске,
    в то время как BeanFactory загружает бины по требованию.
ApplicationContext поддерживает скоупы не только singleton и prototype, автоматически регистрирует
    BeanFactoryPostProccessor (для настройки объявления бинов, перед инициализацией)
    BeanPostProcessor (изменение конкретных бинов, можно до или после, обернуть в прокси)
В BeanFactory для работы с AOP и транзакциями нужно написать еще несколько настроек в коде.



- Что такое BeanFactoryPostProcessor и когда он используется?
интерфейс в Spring Framework, который позволяет изменять определения бинов (BeanDefinition) до того, как Spring создаст сами экземпляры бинов
до инициалазии бинов



- Что такое BeanPostProcessor и чем он отличается от BeanFactoryPostProcessor?
BeanPostProcessor - (так работает autowired) изменять бины после их создания контейнером. BeanPostProcessor позволяет настраивать уже созданные бины перед их использованием.
BeanFactoryPostProcessor - до создания, работает с BeanDefinition

https://javarush.com/groups/posts/1676-spring-framework-vvedenie
https://habr.com/ru/articles/720794/



- Является ли Spring бин потокобезопасным?
не является потокобезопасным по умолчанию (singleton может быть изменен из разных потоков, если он stateful),
    а вот prototype, request, session могут быть потокобезопасными



- Можем ли мы иметь несколько файлов конфигурации Spring?
https://ru.stackoverflow.com/questions/1311996/Несколько-контекстов-в-spring-boot
Да, вы можете иметь несколько файлов конфигурации Spring.
 Вы можете использовать тег <import>


- Для чего нужен Component Scan?
механизм автоматического обнаружения и регистрации бинов в контейнере Spring.



- В чём отличие между @Component и @ComponentScan?
@Component -  пометки класса как компонента Spring.
@ComponentScan - указания пакетов, которые должны быть
    отсканированы для поиска компонентов Spring.



- Для чего используется аннотация @Bean?
 для  метода, который создает и возвращает объект,
 который должен быть зарегистрирован как бин в контейнере Spring.



- В чём разница между @Bean и @Component?
@Component используется для определения бинов на основе классов
@Bean используется для определения бинов на основе методов



- В чём разница между @Component, @Service и @Repository аннотациями?
@Service, @Repository являются производными от @Component
@Service класса, который предоставляет бизнес-логику в приложении.
@Repository класса, который предоставляет доступ к базе данных



- Можем ли мы использовать @Component вместо @Service для бизнес логики?
Да, если нет необходимости в явном разделении слоев приложения,
то можно использовать @Component вместо @Service.




AOP:
- Что вы понимаете под аспектно-ориентированным программированием
        (Aspect Oriented Programming — AOP)?
В ООП ключевой единицей модульности Сlass,
в AOP модульность - Aspect.
Аспекты позволяют модульно организовывать сквозную функциональность


- Когда полезно использовать AOP?
AOP также может быть полезен для устранения дублирования кода,
связанного со сквозной функциональностью, и для улучшения
 разбиения программы на модули


- Что такое Aspect?
класс, который реализует сквозную функциональность
поинкат + адвайс



- Что такое Advice?
метод, который хранится в Aspect



- Что такое Pointcut?
выражение, где в коде должен быть применен advice (совет)



- Что такое JointPoint?
точка метода advice и метода с бизнес-логикой
Класс, благодаря которому мы можем получить информацию о том, где был вызван
конкретный advice



- Что такое Advice Arguments?
аргументы, которые передаются в advice при его вызове



- Что такое AOP Proxies?
создаeтся фреймворком AOP для обеспечения
применения аспектов к целевым объектам
https://habr.com/ru/articles/597797/


- В чем разница между Spring AOP и AspectJ АОП?
AspectJ предоставляет более продвинутые возможности
