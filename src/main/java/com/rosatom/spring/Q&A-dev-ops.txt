- Что такое git?
это распределенная система управления версиями, которая используется для отслеживания изменений в файлах во время разработки программного обеспечения.


- Что делает git commit?
фиксирует изменения в файле или наборе файлов и добавляет их в локальный репозиторий.


- Что делает git push?
отправляет все локальные изменения в удаленный репозиторий


- Что делает git pull?
извлекает изменения из удаленного репозитория и объединяет их с текущей веткой.


- Что делает git fetch?
извлекает изменения из удаленного репозитория, но не объединяет их с текущей веткой.


- Что делает git revert?
создает новый коммит, который отменяет изменения, внесенные определенным коммитом


- Что делает git rebase?
переносит или комбинирует коммиты для улучшения истории коммитов.


- Как создать отдельную ветку?
git checkout -b branch_name


- Как можно разрешать конфликты при слиянии?
можно разрешить вручную, отредактировав файлы с конфликтами, а затем добавив изменения и фиксируя их с помощью git commit

- Что вы знаете о Maven?
это инструмент управления проектами и автоматизации процессов сборки для Java-приложений. Он предоставляет механизмы управления зависимостями, сбора и сборки проектов.


- Как работает Maven?
работает на основе plugins, которые выполняют определенные задачи в
    процессе сборки проекта


- Какова структура maven-проекта?
включает в себя базовые и небазовые директории,
а также файл pom.xml, который содержит информацию о проекте,
такую как имя, версия, зависимости и т. д.


- Как узнать версию maven?
можно узнать из файла pom.xml, который содержит информацию о версии проекта.


- Что такое pom.xml?
project object model


- Какова структура pom-файла?
<project ...>
    **<parent>
    <modelVersion>...
    <name>...
    <artifactId>...
    <version>

    <properties>...

    <profiles>...

    <dependencies>...


- Что такое super-pom?
специальный проект, который содержит макет (template) для создания других
проектов в Maven. Он используется для стандартизации структуры проектов
и обеспечения совместимости.



- Что такое dependency в maven?
зависимость между проектами, которая позволяет одному проекту
использовать функциональность другого проекта.


- Что такое artifact в maven?
единица, которая может быть размещена в репозитории и может быть использована
в проектах. Это может быть класс, JAR-файл или другой файл.


- Что такое plugin в maven?
конвейер, который выполняет определенные задачи в процессе сборки проекта.


- Что такое goal в maven?
цель, которую вы хотите достичь при выполнении проекта.


- Что такое archetype в maven?
шаблон проекта, который используется для автоматического создания нового
проекта с определенной структурой и настройками.


- Что такое repository в maven?
хранилище, которое содержит артефакты и зависимости для проектов.


- Какие типы repository существуют в maven?
локальный, центральный и удаленный

clean (pre-clean, clean, post-clean), default и site - циклы, которые в себе содержать фазы

- Что делает mvn clean?
удаляет временные файлы, созданные в процессе сборки проекта.



- Что такое build profile в maven?
набор настроек, который позволяет определять альтернативные настройки для
проекта, такие как различные конфигурации сборки или профили.


- Что такое SNAPSHOT в maven?
версия артефакта, которая автоматически обновляется с помощью
информации о версиях проектов в репозитории.


- Что такое gradle?
инструмент сборки и автоматизации процессов для Java-приложений, который работает на основе Groovy DSL.


- Чем отличаются maven и gradle?
Gradle, например, поддерживает более сложные зависимости и предоставляет
лучшую гибкость в настройке, благодаря использованию Groovy DSL.
Maven, с другой стороны, основывается на использовании XML и имеет более
строгие конвенции, что делает его менее гибким в настройке.

- Что такое devops?
методология разработки, которая объединяет разработчиков и операционных специалистов для улучшения процессов разработки и развертывания приложений.


- Какие преимущества дает подход devops?
включают улучшение коммуникации между разработчиками и операционными специалистами, ускорение процессов разработки и развертывания, а также повышение качества и надежности приложений.


- Что такое Continuous Integration?
автоматизация процессов интеграции изменений кода от нескольких разработчиков в единый программный проект.


- Что такое Continuous Delivery?
автоматизация процессов развертывания приложений в различные окружения, такие как продакшн, разработка и тестирование.


- Что такое Continuous Deployment?
методика разработки программного обеспечения, при которой изменения в коде автоматически развертываются в рабочую среду после прохождения всех автоматических тестов


- Какие CI-системы вы знаете? В чем отличия Jenkins от TeamCity и других аналогичных систем?
инструменты, которые помогают автоматизировать процессы интеграции и развертывания приложений. Примеры CI-систем включают Jenkins, TeamCity, CircleCI, GitLab
Jenkins - это открытая источник инструмент для автоматизации процессов интеграции и развертывания, который поддерживает большое количество инструментов и плагинов для различных языков программирования и технологий.
TeamCity - это коммерческое разработкающее средство, которое предоставляет функции для автоматизации процессов интеграции, развертывания и управления непрерывными интеграциями.


- Что такое Cloud Computing?
использование вычислительных ресурсов и сервисов в удаленных центрах, которые можно арендовать по мере необходимости.

    память и дисковое пространство.


PAAS предоставляет доступ к операционной системе и средствам развертывания приложений.

- В чем разница между Cloud-решениями и On-premise-решениями?

арендовать по мере необходимости, в то время как On-premise-решениями предоставляют

инфраструктура размещается в вашем офисе и подчиляется вашим командам.

- Чем виртуалки отличаются от контейнеров?
Виртуальные машины (VM): Имеют собственную операционную систему,
    требуют значительные ресурсы. Запускаются на физическом сервере и изолируются друг от друга.
Контейнеры: Делят ядро операционной системы с другими контейнерами.
    Используются для упаковки приложений и их зависимостей, обеспечивают легковесную и быструю изоляцию.


- Что представляет собой докер-контейнер? Что такое namespaces и cgroups?
Docker: Платформа для разработки,
    доставки и запуска приложений в контейнерах.
Namespaces и cgroups: Namespaces обеспечивают изоляцию ресурсов,
    таких как файловые системы и процессы.
    Cgroups (Control Groups) управляют и ограничивают ресурсы, такие как CPU и память.


- Как работает docker?
Docker использует клиент-серверную архитектуру.
Клиент общается с сервером через Docker API.
Docker сервер управляет контейнерами, образами, сетями и томами.


- Что такое dockerfile?
Файл, содержащий инструкции для построения Docker-образа.
Определяет базовый образ, устанавливает зависимости, копирует файлы и настраивает окружение.


- Что такое docker hub?
Облачное хранилище Docker-образов.
Позволяет делиться образами и использовать образы, созданные другими.


- Что такое docker compose?
Инструмент для определения и запуска многоконтейнерных Docker-приложений.
Определение в конфигурационном файле (docker-compose.yml).


- Какие вы знаете инструменты оркестрации контейнеров использовал?
Docker Swarm: Встроенный инструмент Docker для управления кластером Docker-хостов.
Kubernetes: Открытая платформа для автоматизации развёртывания, масштабирования и управления контейнеризированными приложениями.


- Для чего нужен Swarm?
Назначение: Управление кластером Docker-хостов, предоставляет оркестрацию для контейнеров Docker.
Особенности: Прост в настройке, интегрирован в Docker.


- Для чего нужен Kubernetes?
Назначение: Оркестрация и управление контейнеризированными приложениями.
Особенности: Масштабирование, автоматизация развертывания, обнаружение сервисов, управление состоянием и другие возможности.

- Что такое Ansible Task?
Это единичная задача, выполняемая Ansible.
    Задачи описываются в YAML и выполняют конкретное действие на целевом узле.


- Что такое Ansible Module?
Модуль в Ansible - это исполняемый код, выполняющий конкретную задачу. Модули могут быть
    использованы в задачах Ansible для взаимодействия с узлами.


- Что такое Ansible Play?
Play в Ansible - это описательный блок, который объединяет задачи для выполнения
    на конкретных узлах. Play описывает, что нужно сделать на целевых машинах.


- Что такое Ansible Playbook?
Playbook - это файл, написанный на языке YAML, который содержит один или несколько Plays.
    Playbooks используются для автоматизации процессов конфигурации и развертывания.


- Что такое Ansible Role?
Роль в Ansible - это способ организации Playbooks и задач в более структурированный формат.
    Роль может включать в себя переменные, таски, хендлеры и другие компоненты, делая их переиспользуемыми.

Балансировщик (или балансировка нагрузки) - это механизм распределения

- Что такое blue-green deployment, канареечные релизы?
Blue-Green Deployment: Две окружения (blue и green), при этом одно из них активное,
    а другое подготавливается. Переключение между окружениями обеспечивает быстрый и безопасный
    способ внедрения новой версии.
Канареечные релизы (Canary Releases): Постепенное внедрение новой версии для ограниченной группы
    пользователей перед полным развертыванием. Позволяет выявлять проблемы на ранних этапах.

- Что такое мониторинг?
Мониторинг - это процесс отслеживания и сбора данных о состоянии системы или компонентов
    с целью обеспечения их нормальной работы.


- Какие уровни мониторинга вы знаете?
Инфраструктурный мониторинг: Отслеживание состояния серверов,
    сетей и других инфраструктурных элементов.
Мониторинг приложений: Отслеживание производительности и доступности приложений.
Бизнес-мониторинг: Оценка влияния состояния инфраструктуры и приложений на бизнес-процессы.


- Что такое zabbix?
Zabbix - система мониторинга с открытым исходным кодом.
    Позволяет отслеживать состояние различных элементов инфраструктуры,
    а также выполнять уведомления о проблемах.



- Что такое Prometeus?
Prometheus - система мониторинга и оповещения с открытым исходным кодом.
    Основные черты: метрический сбор данных, язык запросов PromQL,
    поддержка динамического обнаружения целей.



- Что такое стек ELK? Зачем он нужен?
настроили аппендеры и пишем в логи с помощью log4j


а в микросервисах операции сквозные (которые затрагивают несколько сервисов)
и нужно единое хранилище логов (некий логгинг сервис) к-ый подтягивает их разных сервисов




ELK - это совокупность трех инструментов: Elasticsearch, Logstash и Kibana.


Elasticsearch: Хранилище и поисковый движок для данных.
Logstash: Система сбора и обработки данных (логов).
Kibana: Интерфейс для визуализации и анализа данных.


Назначение ELK: Сбор, хранение и анализ логов, что позволяет выявлять и решать проблемы, проводить мониторинг и анализ производительности.
