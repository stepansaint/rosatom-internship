JDBC:
- Что такое Spring JDBC?
предоставляет уровень абстракции над JDBC, который упрощает кодирование
и уменьшает количество шаблонного кода


- Чем Spring JDBC отличается от JPA?
JPA (Java Persistence API) - это стандартный способ работы с базами данных в Java,
Spring JDBC, с другой стороны, предоставляет более низкоуровневый подход
к работе с базами данных через JDBC API


- В чем преимущества Spring JDBC перед обычным JDBC?
упрощает кодирование и уменьшает количество шаблонного кода,
необходимого для выполнения операций с базой данных.


- Расскажите о классе JDBCTemplate.
JdbcTemplate - это класс в Spring JDBC, который предоставляет
удобный способ выполнения операций с базой данных через JDBC API.


- Какие методы есть у класса JDBCTemplate?
execute(String sql)
query(String sql, RowMapper<T> rowMapper)
update(String sql, Object... args)
call(CallableStatementCreator csc, List<SqlParameter> declaredParameters)


- Что такое NamedParameterJdbcTemplate?
предоставляет удобный способ выполнения SQL-запросов с
именованными параметрами вместо обычных позиционных параметров.



- Что такое MapSqlParameterSource?
предоставляет удобный способ создания объекта SqlParameterSource,
используемого для передачи параметров в NamedParameterJdbcTemplate.
Он предоставляет методы для добавления параметров в объект SqlParameterSource

https://javarush.com/quests/lectures/questspring.level03.lecture14

- Зачем нужен SimpleJdbcInsert?
предоставляет удобный способ выполнения операций вставки данных в базу данных,
используя именованные параметры



- Зачем нужен SimpleJdbcCall?
предоставляет удобный способ вызова хранимых процедур в базе данных






Data:
- Что такое Spring Data?
проект, который предоставляет абстракции для работы с реляционными и нереляционными базами данных
(spring data jpa, spring data jdbc, spring data mongodb...)



- Какие модули Spring Data вы знаете для работы с нереляционными СУБД?
Spring Data MongoDB
Spring Data Cassandra
Spring Data Redis



- С какими хранилищами Spring Data позволяет работать?
Реляционные (MySQL, PostgreSQL, Oracle),
Нереляционные (MongoDB, Redis, Cassandra)



- Что такое Spring Data JPA?
предоставляет абстракцию для работы с JPA.
Spring Data JPA предоставляет репозитории,
которые позволяют выполнять CRUD-операции и другие операции с базой данных


- Зачем нужен JpaRepository<>?
интерфейс, расширяет CrudRepository и позволяет выполнять дополнительные
операции с базой данных, такие как сортировка, пагинация


- Что такое CrudRepository?
интерфейс, предоставляет базовые методы для выполнения CRUD-операций


- Объясните запись public interface CrudRepository<T, ID extends Serializable> extends Repository<T, ID>.
Он расширяет интерфейс Repository и принимает два параметра:
T - тип сущности, с которой работает репозиторий, и
ID - тип идентификатора сущности.
Repository - это базовый интерфейс Spring Data, который определяет методы для работы с базой данных.


- ЧТо такое PagingAndSortingRepository?
интерфейс Spring Data, который расширяет CrudRepository
и добавляет поддержку пагинации и сортировки результатов запроса.


- ЧТо такое QueryDslJpaRepository?
интерфейс Spring Data JPA, который расширяет JpaRepository и добавляет поддержку
QueryDSL - библиотеки для создания типобезопасных SQL-запросов.


- Что такое Automatic Queries и особенности работы с ними.
позволяет создавать запросы на основе имен методов репозитория


- Какую роль играет аннотация @Query?
позволяет написать SQL-запрос или JPQL-запрос внутри метода репозитория.
может быть полезно, если вы хотите выполнить сложный запрос,
который нельзя создать с помощью Automatic Queries.


- Что такое JPQL?
Java Persistence Query Language) - это язык запросов, который используется в JPA
для выполнения запросов к базе данных.
Он похож на SQL, но использует объектную модель вместо таблиц базы данных.


- Можно ли в Spring Data использовать HQL?
да, парсит и jpql и hql (если hibernate представлен в classpath)


- Зачем нужна аннотация @NamedQuery?
позволяет определить запрос в классе сущности
и использовать его в различных местах приложения.


- Зачем нужна аннотация @EnableJpaRepositories?
используется в Spring для включения поддержки репозиториев JPA.
Она позволяет указать базовый пакет, в котором находятся интерфейсы
репозиториев, и другие настройки.
